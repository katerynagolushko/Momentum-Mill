# Fundraising Sprint program (archived, not public)

These are the full Fundraising Sprint program pages. They used to be live on
momentummill.com. On 2026-07-17 they were pulled off the public site because the
whole program should not be visible yet: people should have to book a call to see it.

They are kept here so the work is saved and not forgotten. This folder lives in the
repo but is **outside `docs/`**, so GitHub Pages does **not** serve it. Nothing on the
live site links to these files.

## What's here

- **`raise-campaign-offer.html`**: the full offer, long form, with the timeline and
  booking-UI graphs. This is the complete program doc. Open it in a browser to read it.
- **`fundraising-sprint.html`**: the shorter, scannable program page.
- **`raise-campaign.pdf.html`**: older standalone PDF-style page (legacy).

Each file is self-contained (fonts and graphs are inline), so any of them renders on
its own just by opening it.

## To put the program back on the public site

Move the file(s) back into `docs/`, add a link to it from `docs/index.html` (the
Fundraising Sprint card), then commit to `main` and push. Pages rebuilds in about a
minute.
