Plan · handoff · recover · duration

Built for long runs, not one-shot chats

  • Plan: each agent writes a short plan before acting (visible in logs)
  • Handoff: Scout→Analyst→Voice→Publisher; Analyst→Strategist for amplify
  • Recover: rate limits, tone fails, publish 503s — backoff, rewrite, retry
  • Duration: demo cycle ~24s sped-up; production never ends until paused
Real output

  • 1 X reply shipped (after recover from API 503)
  • 1 Reddit reply queued for founder approve
  • 2 proactive plays (founder thread + LinkedIn amplify)
