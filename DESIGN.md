# Design System — Vigil

## Visual Theme
Control tower at 2am — bottle-green signal lights, amber alerts, pure black glass. Operators watch live brand noise; agents hand work across desks.

## Colors (OKLCH)
- `--bg`: oklch(0.10 0 0)
- `--surface`: oklch(0.15 0 0)
- `--surface-2`: oklch(0.19 0 0)
- `--ink`: oklch(0.96 0 0)
- `--muted`: oklch(0.68 0 0)
- `--primary`: oklch(0.62 0.12 160)
- `--accent`: oklch(0.78 0.14 75)
- `--danger`: oklch(0.65 0.18 25)
- `--line`: oklch(0.28 0 0)

## Typography
- UI: Outfit
- Logs/mono: JetBrains Mono

## Strategy
Restrained product UI. Primary for live/active states. Accent for alerts and CTAs needing attention.
